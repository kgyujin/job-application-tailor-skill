# 상세 체크리스트

SKILL.md 7단계 요약 체크리스트의 확장판. 분량이 많거나 여러 공고를 동시에
처리할 때, 혹은 결과물 품질을 꼼꼼히 재검토할 때 이 문서를 참조한다.

## A. 채용공고 분석 단계

- [ ] 필수 자격요건과 우대사항을 명확히 구분했는가
- [ ] "주요 업무"에서 실제로 매일/자주 하게 될 일을 파악했는가 (직무명만으로 추측하지 않음)
- [ ] 공고에 언급된 기술 스택의 정확한 표기(대소문자, 버전, 약어)를 확인했는가
- [ ] 회사/팀이 반복 사용하는 어휘(가치관, 문화 키워드)를 3개 이상 추출했는가
- [ ] 지원 마감일, 제출 형식(파일 형식, 글자수 제한 등) 제약을 확인했는가

## B. 매칭 단계

- [ ] 필수 자격요건 각각에 최소 1개 이상의 실제 근거를 매칭했는가, 없다면 gap으로 명시했는가
- [ ] 우대사항 중 매칭 가능한 항목을 놓치지 않았는가
- [ ] 매칭 근거가 원본 서류에 실제로 존재하는 문장/사실인지 재확인했는가 (지어내지 않음)

## C. 이력서 단계

- [ ] 상단 요약/목표(있는 경우)가 이번 공고 직무명과 일치하는가
- [ ] 경험 순서가 공고 관련성 기준으로 재배치되었는가
- [ ] 정량적 성과가 과장 없이 원본 수치 그대로 유지되었는가
- [ ] 공고에 없는 기술/툴을 새로 추가하지 않았는가
- [ ] 원본 양식(글꼴, 여백, 섹션 순서 등 시각 포맷)을 훼손하지 않았는가

## D. 자기소개서 단계

- [ ] 회사명/직무명이 실제 지원 대상과 정확히 일치하는가
- [ ] 핵심 요구사항과 연결된 경험이 상황-행동-결과(STAR) 구조로 구체적인가
- [ ] 다른 회사 이름/문구가 실수로 남아있지 않은가 (재사용 자소서 특유의 사고)
- [ ] 글자수/분량 제한을 초과하지 않았는가
- [ ] 문체가 원본 자소서의 어조와 일관되는가

## E. 포트폴리오 단계

- [ ] 공고 기술 스택과 가장 관련 있는 프로젝트가 우선 노출되는가
- [ ] 프로젝트 설명에서 기술적 의사결정과 성과가 드러나는가
- [ ] 원본 포트폴리오 파일을 직접 수정하지 않고 조정 메모로 분리했는가

## F. 최종 제출 전

- [ ] 모든 산출물이 새 파일로 저장되고 원본이 보존되었는가
- [ ] gap 항목을 사용자에게 명시적으로 보고했는가
- [ ] 오탈자, 회사명/직무명 혼용 여부를 마지막으로 검토했는가
